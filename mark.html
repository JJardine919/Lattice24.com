Using it

  • The mark carries no baked colours. Members are currentColor; the glow points read --l24-accent, so each page hands it the accent it already uses — amber here, green on the calculator and audit tool.
  • Inline it rather than linking it, so it inherits colour and follows dark mode. It is small enough that this costs nothing.
  • Give it clear space of about one node diameter on every side. Do not recolour the glow points independently of the members.

Pulled 2026-08-24 — The Problem

UNSHOWN, NOT REFUTED · l24_001
This video was pulled on 2026-08-24 because it closed on a capability we have not shown: "We catch drift without a reference cell." Nothing contradicts that sentence. It is not refuted, and this is deliberately not filed with the withdrawal above — those two videos were taken down because a control killed the claim, which is a different and worse thing. This one came down because when we asked which result file backed it, there wasn't one. What we do have is real and is less than the sentence claimed. In branch_work/18809407_gas/results/claim2_drift.json, ethanol's per-batch entropy rises from 0.1597 at batch 1 to 0.4373 at batch 10, and it rises on all 16 sensors. That is a monotone increase on data that is drifting. It is not a detection result: there is no alarm, no threshold, no false-positive rate, and no comparison against any method that does use a reference cell. Drift is a ramp, and this engine responds to ramps generally, so a rising number on drifting data is the weakest possible evidence that anything was caught. We are not replacing it with a softer version of the same claim. It comes back when there is a result file showing drift detected, with the rate at which it fires on sensors that are not drifting.

Withdrawn 2026-08-23 — Separation You Can Count On

CLAIM WITHDRAWN · l24_005
This video was withdrawn on 2026-08-23 on a matched control that had not been run before. It rested on "six gases separate by entropy signature at 18.5 sigma" from a public 13,910-sample gas array. The gases do not sit evenly across the ten measurement batches, so the pooled comparison mixes gas with batch. Holding batch fixed and shuffling only the gas labels — 1000 draws, each pseudo-gas keeping the real gas's exact per-batch counts — reaches 18.44 sigma in 247 of them. p = 0.25. The control we had published, p = 0.003, permutes all 13,910 samples at once, which destroys the batch structure along with the labels, so it never tested this. Separately, the recipe's rolling window steps by one sample, so consecutive windows share 19 of their 20 readings. Lag-1 autocorrelation is 0.986 and the effective sample size is about 46 against a naive 1622 — the sigma values in this family are inflated roughly sixfold, independent of the batch question. What survives, stated plainly: inside batch 7 alone the separation is real and large — 36.42 sigma observed, and none of 1000 shuffles came near it. Inside batch 10 alone there is nothing — 5.94 observed against a shuffled mean of 6.85, p = 0.72. Two batches, opposite answers. That is a genuine per-batch result, and it is not "six gases separate." Control: qbh/green2_gas_within_batch_null.json. Nothing replaces it yet; we will not re-publish the number until it stands on a control that can kill it.

What "recomputed" means here. Claims are checked against two tiers of authority. A result file — JSON, CSV, a run log written by a script that measured something — can certify a number. Prose cannot: not a summary document, not a README, not a constant typed into source code. A write-up asserting a figure is a restatement of it, not evidence for it.

So the figures on this page are not looked up. The checker opens the result file and redoes the arithmetic every time the page is built. If that arithmetic stopped landing, the page would not build.

The gas separation that used to appear here still recomputes, and it lands at 18.44σ with 11 of 15 pairs beyond 3σ. It read 18.53σ until 2026-08-23, when the divisor was corrected: the check had been dividing by the per-species sample count on a statistic computed over windows, of which there are 20 fewer per species. 18.44 is also the value the matched control was built against, so the two now agree.

That arithmetic is not what withdrew the claim, and recomputing a number is not the same as testing it. A control did — see the withdrawal notice above. A figure can be reproducible and still be measuring the wrong thing.

Claims we cannot certify this way are marked unverified and are simply absent from this page. Unverified is not a claim that they are false — it means nobody has shown them yet, which is a different and more honest thing to say. Those counts are kept separate and never added together.
